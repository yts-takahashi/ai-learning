## 役割

以下の3トラックをサブエージェントで並列実行し、プロジェクトを完成させる。

```
[サブエージェントA] ship      → Next.jsアプリの実装
[サブエージェントB] content   → 121レッスンの教材作成
[サブエージェントC] chronicle → 開発プロセスの記録
```

## 実行前の準備

1. `docs/PRD.md` を読んで全体像を把握する
2. `src/` と `content/` の現状を確認して進捗を把握する
3. 各サブエージェントへの指示を組み立てる

## サブエージェントへの指示

### サブエージェントA: ship（アプリ実装）

```
以下のタスクを実行してください：

スキルパス: .claude/skills/ship/SKILL.md
タスク: docs/PRD.md を読み、実装タスク（フェーズ1〜2）の
       未完了項目をすべて実装してください。
       フェーズ3（コンテンツ）はサブエージェントBが担当するためスキップしてください。
```

### サブエージェントB: content（教材作成）

```
以下のタスクを実行してください：

スキルパス: .claude/skills/content/SKILL.md
タスク: docs/PRD.md のカリキュラムに従い、
       content/lessons/ に全121レッスンのMarkdownファイルを作成してください。
       アプリの実装完了を待たずに進めてください。
```

### サブエージェントC: chronicle（記録）

```
以下のタスクを実行してください：

スキルパス: .claude/skills/chronicle/SKILL.md
タスク: 開発の進捗を定期的に確認し、
       docs/journal/ に開発ジャーナルを記録してください。
       ship・content の進捗を git log と docs/PRD.md で追跡してください。
       30分ごとに最新状況を記録に追記してください。
```

## 並列実行の注意点

- A・B・Cは同時に起動する（順番に起動しない）
- AとBは独立しているため互いに待たない
- Cは定期的にA・Bの状況を確認して記録する

## 完了条件

- PRD の全実装タスク（フェーズ1〜2）に `[x]` がついている
- `content/lessons/` に全121レッスンのファイルが存在する
- `docs/journal/` に開発記録が残っている

## 完了報告

全サブエージェント完了後、以下を報告する：
- 作成されたファイル数
- 実装された機能一覧
- 開発ジャーナルの場所
- `npm run dev` での確認方法
